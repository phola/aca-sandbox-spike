# ACA Sandbox Spike

A 3D replay of a spike on [Azure Container Apps Sandboxes](https://sandboxes.azure.com/docs/sandboxes) in UK South, 22–23 October 2026. Each scene plays one test at its measured timings:
- suspend and resume
- golden snapshots and clones
- memory scaling
- network fences
- a DuckDB 2.0 Quack data server
- the doorbell and sidecar wake patterns
- a 25-agent stress run

Below the scenes is the UK South price ledger.

View it at **https://phola.github.io/aca-sandbox-spike/**.

`index.html` is a single static page: three.js comes from jsDelivr and fonts from Google Fonts, and the data is built in.
